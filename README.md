# Task Manager API

## Practical 4 - Express.js REST API

A simple Task Manager API built using Express.js.

### Features
- GET /tasks → Get all tasks
- POST /tasks → Add a new task
- PUT /tasks/:id → Update a task
- DELETE /tasks/:id → Delete a task

### Technologies Used
- Node.js
- Express.js

### Project Structure

task-manager-api/
├── server.js
├── package.json
├── package-lock.json
└── .gitignore

### Run Project

```bash
npm install
node server.js
```

Server runs on:
http://localhost:5000
